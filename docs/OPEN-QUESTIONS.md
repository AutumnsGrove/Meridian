# Open questions

Questions the docs do not answer, raised by whoever is changing the project and could not resolve them
from the docs, the code, or an obviously reversible default. The preferred route for a question that
blocks work is the question tool (see `AGENTS.md`, "Asking the owner"); this file is the fallback for
when that tool is unavailable or unanswered, and for lower-priority questions that do not block the
change. A settled question is appended to [DECISIONS.md](DECISIONS.md) as a new numbered entry and
removed from here.

Rules:

- Raise a question only if you cannot resolve it from the docs, the code, or a sensible default that
  is obviously reversible.
- Always include your recommended answer. The owner should be able to reply "yes".
- After raising it, skip to the next unblocked change. Do not build on a guess.

## Format

```
### Q<n>: short title
- **Asked:** YYYY-MM-DD
- **Context:** what you were doing and what the docs say or do not say
- **Options:** A, B (one line each)
- **Recommendation:** which, and why
```
